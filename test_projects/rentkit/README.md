# RentKit

Внутренний сервис проката фото- и видеотехники: камеры, объективы, свет, звук, штативы и
прочий грип. Клиент бронирует технику на сайте, приезжает в пункт выдачи, забирает комплект
и возвращает его в оговорённый срок. Мы считаем стоимость аренды, держим депозит на карте
и начисляем штраф за просрочку.

Пункт выдачи один, физический, с рабочими часами: **пн–сб 10:00–20:00, воскресенье — выходной**.

## Структура монорепозитория

```
rentkit/
├── packages/
│   └── core/          # общие правила: тарифы, доступность, депозиты, штрафы
├── apps/
│   ├── api/           # Express + TypeScript + Postgres (pg), порт 8030
│   └── web/           # React + Vite, личный кабинет и каталог
└── tsconfig.base.json
```

`packages/core` — единственный источник правды по бизнес-правилам. Ни API, ни веб не должны
заводить свои копии формул: всё, что касается денег и сроков, живёт в core и импортируется
как `@rentkit/core`.

## Запуск

```bash
npm install
cp .env.example .env          # заполнить DATABASE_URL и ключи
npm run db:schema             # накатить apps/api/src/db/schema.sql
npm run dev                   # api на :8030, web на :5173
```

Отдельно:

```bash
npm run dev:api
npm run dev:web
npm run typecheck
npm run test
```

## Правила ценообразования

Все суммы в копейках (`*Kop`, целое число). Округление — до копейки, вниз.

1. **База.** Количество суток аренды × `dayRateKop` товара. Неполные сутки округляются вверх,
   минимальный срок аренды — 1 сутки. Почасовой тариф (`hourRateKop`) применяется только для
   внутренних пересчётов и продлений в день выдачи.
2. **Выходная наценка.** За каждые сутки, попадающие на субботу или воскресенье, +20 % к
   дневному тарифу. Наценка считается по каждому дню отдельно, а не по всему заказу.
3. **Скидка за длительный срок.** При аренде от 7 суток — −15 % от суммы аренды с учётом
   выходной наценки. Введена с сентября, на более ранние брони не распространяется.
4. **Депозит** в стоимость аренды не входит и в `totalKop` не попадает — он показывается
   отдельной строкой и блокируется на карте.

Итог: `totalKop = baseKop + weekendKop − longTermDiscountKop`.

Разбивка приходит в поле `lines` — массив `QuoteLine { code, title, amountKop }`, его же
показывает веб в карточке брони.

## Депозит

На каждый товар заведён `depositKop`. Для проверенных клиентов (`verified === true`) с
рейтингом 4.5 и выше депозит уменьшается на 30 %.

Депозит не списывается, а **холдируется** на карте: при подтверждении брони API вызывает
`POST /api/payments/hold` и сохраняет идентификатор холда в `bookings.deposit_hold_id`.

Холд снимается автоматически в двух случаях:

* техника принята обратно в пункте выдачи (`POST /api/returns`) — из холда удерживается
  штраф за просрочку и стоимость повреждений, остаток возвращается клиенту;
* бронь отменена (`POST /api/bookings/:id/cancel`) — холд снимается целиком, без удержаний,
  если отмена произошла не позже чем за 24 часа до начала аренды.

Ручное снятие холда доступно сотрудникам через `POST /api/payments/release`.

## Штрафы

* Льготный период после срока возврата — 120 минут.
* Просрочка считается в рабочих часах пункта выдачи: если срок истёк в воскресенье, отсчёт
  начинается с понедельника, 10:00.
* Штраф за сутки просрочки — полуторный дневной тариф, но не больше суммы депозита.
* Повреждения оцениваются приёмщиком по шкале `scratch / minor / major / total`.

## API

Базовый адрес — `http://localhost:8030`.

| Метод  | Путь                            | Назначение                          |
|--------|---------------------------------|-------------------------------------|
| GET    | `/api/items`                    | каталог с фильтрами                 |
| GET    | `/api/items/:id`                | карточка товара                     |
| GET    | `/api/items/:id/availability`   | занятые интервалы на период         |
| POST   | `/api/bookings`                 | создать бронь                       |
| GET    | `/api/bookings`                 | список броней                       |
| GET    | `/api/bookings/:id`             | детали брони                        |
| POST   | `/api/bookings/:id/cancel`      | отменить бронь                      |
| POST   | `/api/bookings/:id/quote`       | пересчитать стоимость               |
| POST   | `/api/returns`                  | принять возврат                     |
| POST   | `/api/payments/hold`            | заблокировать депозит               |
| POST   | `/api/payments/release`         | снять блокировку депозита           |
| GET    | `/api/reports/revenue`          | выручка по периодам и топ товаров   |
| GET    | `/api/customers/:id`            | карточка клиента и история          |

Все ответы — JSON. Ошибки приходят в виде `{ "error": { "code", "message", "details" } }`.

## Роли

* `staff` — сотрудники пункта выдачи: возвраты, отмены, отчёты, ручные операции с депозитом.
* `customer` — клиент: свои брони и каталог.

Токен передаётся заголовком `Authorization: Bearer <jwt>`.
