# Роадмап

## Сделано (v0.1)

- Авторизация, проекты, выбор каталога, фоновая индексация с diff-отчётами
- Граф знаний Neo4j: структура + ИИ-анализ файлов + синтез обзора
- Чат (SSE, Opus 5 по умолчанию, выбор reasoning), MCP-инструменты проекта
- Канбан + извлечение задач из материалов + ИИ-проверка выполненности
- Whisper-транскрибация, извлечение текста из документов
- RLM-движок, суб-агент актуализации графа, генератор плагинов Claude Code
- Соглашения проекта (Decisions), RLM-проработка задач, импорт истории git
- Тесты на фейковом claude

## Сделано (v0.2)

- SSE-пуш прогресса фоновых задач и событий канбана (вместо поллинга каждые 3с)
- Очередь анализа: автопродолжение бэклога («до конца бэклога» на вкладке Обзор)
- Отмена фоновых задач из UI (✕ на панели прогресса); ретраи упавших батчей —
  транзиентный сбой сразу, файлы-error при ручном «Обновить индекс»
- Экспорт карты знаний в markdown (кнопка «Экспорт .md»)
- Деталка задачи: файлы с ролями (AFFECTS из графа + RLM) и история worklog
- Alembic-миграции вместо create_all (старые установки стампятся автоматически)

## Сделано (v0.3)

- Планировщик: задача с созвона → RLM-исследование → общий план → декомпозиция
  в подзадачи канбана с зависимостями (depends_on, рёбра DEPENDS_ON/SUBTASK_OF в графе);
  кнопка «Декомпозировать» в задаче, MCP-инструмент task_plan для чата и плагина
- Наблюдение за каталогом (watchdog) — правки в коде с дебаунсом сами запускают
  инкрементальный индекс; включается галкой на Обзоре, переживает рестарт сервера

## Сделано (v0.4)

- Векторный поиск по знаниям: Qdrant + локальные эмбеддинги (fastembed, ONNX,
  без API-затрат); /graph/search стал гибридным — fulltext Neo4j + семантика,
  находит файлы, выжимки материалов и соглашения и по точным словам, и по смыслу
- Мультирепо-проекты: несколько каталогов на проект (например, отдельные репозитории
  бэкенда и фронтенда); файлы дополнительных корней живут с префиксом «алиас/»
  в реестре, графе, векторах и канбане; ИИ-анализ идёт с cwd своего корня,
  watchdog наблюдает за всеми корнями, git-импорт видит все репозитории
